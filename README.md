# UI Style Scout · 组件样式选型

根据组件截图、名称或文字描述，跨 UI 组件网站搜索并筛选样式，提供真实预览、具体来源链接，以及场景与技术栈适配建议。

调用名：`$ui-style-scout`。

## 能做什么

- 接收截图、文字、组件名、链接，寻找相似款、风格变体或适合现有页面的方案。
- 覆盖 23 类组件，包括按钮、表单、下拉选择、导航、弹窗、表格、上传、编辑器、图表、聊天和移动端组件，也支持局部组合界面。
- 提供 36 个来源入口，并通过中英文同义词和交互模式继续搜索清单以外的组件。
- 默认给出 3～5 个有实质差异的候选，说明样式差异、适用场景和项目适配情况。
- 区分可参考代码、当前项目可用实现、视觉参考和无样式交互基础。

## 使用示例

可以先发送截图，再输入：

```text
用 $ui-style-scout 找几个与这张截图相似、但更精致的样式。
```

也可以直接描述：

```text
用 $ui-style-scout 帮我找 3～5 个适合 Vue 后台的多选下拉框，
需要搜索、分组和已选项回显，附预览与具体来源链接。
```

```text
用 $ui-style-scout 找几种简洁的聊天输入框，
需要附件入口和模型选择，风格贴近我现有页面。
```

默认先展示候选供用户选款。用户要求“把第 2 个用到项目里”时，再按项目既有流程修改代码；已经授权选型并实现时，不重复要求确认。

## 安装

本仓库根目录就是 skill 目录。下载或克隆后，将其以 `ui-style-scout` 为目录名，放到个人 skills 目录中，例如：

```text
~/.codex/skills/ui-style-scout/
├── SKILL.md
├── agents/openai.yaml
└── references/
```

如果配置了 `CODEX_HOME`，则使用其下的 `skills/ui-style-scout/`。已有同名目录时，保留个人定制内容后再合并。也可以让 Codex 从 GitHub 仓库 `bruceoxygenrain/ui-style-scout` 的根目录安装此 skill。

## 工具与使用边界

实时跨站搜索需要可用的联网工具；获取动态状态或真实截图时，可使用环境提供的浏览器或计算机操作能力。此仓库不包含额外的搜索服务、截图程序或访问凭据。

无法获得真实预览或访问具体页面时，会说明缺口，不用生成图冒充网站实例。网站费用、授权、依赖和版本以当次官方信息为准，来源表不是固定排名，也不限制使用新来源。

默认遵循原作者的协作分工：界面、样式和入口由用户手动测试；构建、类型检查、lint 和代码检查由用户安排其他 agent。使用者当前指令和项目 AGENTS.md 优先。
